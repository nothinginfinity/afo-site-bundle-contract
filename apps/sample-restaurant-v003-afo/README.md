# sample-restaurant-v003-afo

Preview-only Worker app mirror for Restaurant v0.03, a visual-first restaurant demo with real remote image URLs, menu tabs, event packages, sticky CTA, and gallery snippet.

This app is separate from `sample-restaurant-afo` and `sample-restaurant-v002-afo`.

Guardrails:

- workers.dev preview only
- No production routes
- No custom domains
- No account IDs
- No secrets
- No production receipt
- `deployment.confirmed` must remain false
