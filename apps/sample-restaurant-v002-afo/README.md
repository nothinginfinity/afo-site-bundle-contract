# sample-restaurant-v002-afo

Preview-only Worker app mirror for the Restaurant v0.02 premium demo bundle.

This app is separate from the live baseline `sample-restaurant-afo` Worker and is intended for workers.dev preview deployment only.

Guardrails:

- No production routes
- No custom domains
- No account IDs
- No secrets
- `deployment.confirmed` must remain false
- Preview deploy only through Worker Transport after validation
